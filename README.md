# HONOR AL-DIWANIYAH — متجر إلكتروني (نسخة تأسيسية)

هذه حزمة بداية لمتجر عربي متجاوب، بألوان التركواز والرمادي والأبيض. تحتوي على واجهة المتجر، سلة، نموذج طلب، صفحة إدارة أولية، ومخطط قاعدة بيانات Supabase.

## التشغيل التجريبي
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح أو شغّل مجلد المشروع عبر خادم محلي.
3. أضف المنتجات للسلة وجرّب إكمال الطلب.
4. افتح `admin.html` لمعاينة لوحة الإدارة التجريبية.

> من دون ربط Supabase، الطلبات والمنتجات التجريبية تُحفظ محلياً في نفس المتصفح فقط. هذه ليست نسخة منشورة ولا تستقبل طلبات فعلية من الزبائن.

## ربط قاعدة البيانات
1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase-schema.sql`.
3. انسخ Project URL و anon/public key إلى `config.js`.
4. أنشئ أول مستخدم من Authentication ثم أضف UUID الخاص به كمدير عبر أمر SQL الموجود في نهاية ملف المخطط.
5. أنشئ حسابات الموظفين من Authentication، ثم أضف UUID لكل موظف في `profiles` مع role=`staff`.
6. أضف المنتجات إلى جدول `products`.

## ملاحظات قبل الإطلاق
- صفحة الإدارة الحالية نموذج أولي، وتحتاج إكمال ربط CRUD والمصادقة والصلاحيات على قاعدة البيانات قبل استخدامها فعلياً.
- لا تضع `service_role` key في ملفات المتصفح مطلقاً. استخدم anon/public key فقط مع سياسات RLS.
- الدفع الإلكتروني غير مفعّل؛ خيار الدفع الإلكتروني معطّل عمداً إلى حين اختيار مزود دفع عراقي/متاح قانونياً وربط واجهته الخلفية والتحقق من webhooks.
- أسعار وصور المنتجات الموجودة أمثلة توضيحية، ويجب مراجعتها وتحديثها من قبل المتجر.
- تمت إضافة شعار المحل المرسل بصيغته الأصلية داخل `assets/honor-al-diwaniyah-logo.png`، وإضافة بيانات التواصل المعتمدة في التذييل. قبل النشر يجب تأكيد رقم الهاتف والعنوان، وإضافة سياسة الاستبدال والاسترجاع، أجور التوصيل، وشروط الخصوصية.

## البنية
- `index.html` — واجهة المتجر
- `styles.css` — التصميم المتجاوب والهوية
- `app.js` — البحث، الأقسام، السلة، وإرسال الطلب
- `admin.html` — نموذج لوحة الإدارة
- `config.js` — إعدادات الربط
- `assets/honor-al-diwaniyah-logo.png` — شعار المتجر الأصلي
- `supabase-schema.sql` — قاعدة البيانات وسياسات الوصول
